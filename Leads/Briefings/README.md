# Briefings

All **lead briefing** `.txt` files live in **subfolders by track** so `Leads/` root stays a stable entry point (`README` + **template** only).

## Layout

| Folder | Contents |
|--------|----------|
| **[`Europe/`](Europe/)** | Named contacts with EU / Netherlands context |
| **[`Paraguay-pipeline/`](Paraguay-pipeline/)** | Paraguay SMB pipeline + vertical research tracks (Ai-Whisperers org) |

## Conventions

| Item | Convention |
|------|------------|
| **Naming** | `Lead Briefing – {Name or company}.txt` |
| **Template** | Copy from `../_TEMPLATE – Lead Briefing (15-min discovery).txt` (parent `Leads/` folder) |
| **Rules** | `.cursor/rules/outreach/lead-briefing-standard-rule.mdc` |
| **Pricing / quotations** | Same track under [`../../Pricing/quotations/`](../../Pricing/quotations/README.md) |
