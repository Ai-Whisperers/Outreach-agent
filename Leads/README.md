# Leads

Single place for **pre-discovery** and **first-call** preparation. Each lead has one briefing file the team can open before the free ~15-minute call.

**Email sent/received history** lives under [`../Outreach/email-history/`](../Outreach/email-history/README.md) (link threads to briefings from there).

**Pricing** (internal numbers, packaging): [`../Pricing/`](../Pricing/README.md)

## Folder layout

```text
Leads/
  README.md                                    ← you are here
  _TEMPLATE – Lead Briefing (15-min discovery).txt   ← copy for every new lead
  Briefings/
    README.md                                  ← index of all briefing tracks
    Europe/                                    ← named EU / NL contacts
    Paraguay-pipeline/                         ← Paraguay SMB + vertical pipelines
```

Start new briefings from the **template** in this folder; save the completed file under the right **`Briefings/<track>/`** subfolder (see [`Briefings/README.md`](Briefings/README.md)).

## Conventions

| Item | Convention |
|------|------------|
| **Naming** | `Lead Briefing – {Name or company}.txt` |
| **Template** | Copy `_TEMPLATE – Lead Briefing (15-min discovery).txt` |
| **Cursor rules** | `.cursor/rules/outreach/lead-briefing-standard-rule.mdc` |
| **Where to save** | [`Briefings/`](Briefings/README.md) — pick `Europe/`, `Paraguay-pipeline/`, or add a new track folder |

## Why this matters

The first short call sets **project direction** and strongly influences **whether the client buys**. Briefings should front-load **pitch angle**, **pricing signals**, and a **tight discovery agenda**—not only logistics.

## After the call

Update the same briefing (or add a dated subsection) with confirmed facts so the proposal and CRM stay aligned.
