# Email threads

Add **one file or one subfolder per conversation** (same external counterparty + same topic). New threads go here; older ones stay in place for history.

Start from [`../README.md`](../README.md) for naming and privacy rules.

**Language:** internal notes in **English**; client-facing copy in the **lead’s language** (often Dutch for NL leads) — see `rule.outreach.language-locale.v1`.
